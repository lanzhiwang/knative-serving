# YAML-based installation

* https://knative.dev/docs/install/yaml-install/

You can install the Serving component, Eventing component, or both on your cluster by applying YAML files.
您可以通过应用 YAML 文件在集群上安装 Serving 组件、Eventing 组件或两者都安装.

- [Install Knative Serving with YAML](https://knative.dev/docs/install/yaml-install/serving/install-serving-with-yaml/)

- [Install Knative Eventing with YAML](https://knative.dev/docs/install/yaml-install/eventing/install-eventing-with-yaml/)
